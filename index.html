스케줄 & 생산성 개인정보처리방침

핵심 요약: '스케줄 & 생산성' 앱은 사용자의 어떠한 개인정보도 외부 서버로 전송하거나 수집하지 않으며, 모든 데이터(일정, 할 일, 목표 등)는 오직 사용자의 기기 내부(Local Storage)에만 암호화 저장됩니다.

1. 수집하는 개인정보 항목

'스케줄 & 생산성' 앱은 별도의 회원가입이나 계정 연동 절차가 없으며, 이름, 전화번호, 이메일, 위치 정보 등의 식별 가능한 개인정보를 서버로 수집·저장·전송하지 않습니다.

  • 사용자가 입력하는 데이터: 할 일, 캘린더 일정, 목표, 뽀모도로 집중 기록 등
  • 저장 방식: 전적으로 기기 내부 로컬 저장소(AsyncStorage / SQLite)에만 물리적으로 저장되며, 외부 클라우드나 개발자 서버로 일체 전송되지 않습니다.

2. 앱에서 사용하는 기기 권한 및 목적

본 앱은 원활한 기능 제공을 위해 최소한의 시스템 권한만을 요구하며, 본래 목적 이외의 용도로 활용하지 않습니다.

  • 알림 표시 권한 (POST_NOTIFICATIONS): 사용자가 설정한 일정 시작 알림, 데일리 루틴 리마인더를 기기 상단바에 표시하기 위해 사용됩니다.
  • 정밀 알람 권한 (SCHEDULE_EXACT_ALARM, USE_EXACT_ALARM): 배터리 절전 모드에서도 사용자가 지정한 시각 정시에 오차 없이 알림을 울리도록 보장하기 위해 사용됩니다.
  • 진동 권한 (VIBRATE): 알림 도래 시 햅틱 피드백 및 진동을 울리기 위해 사용됩니다.
  • 재부팅 수신 권한 (RECEIVE_BOOT_COMPLETED): 기기를 재부팅했을 때 사용자가 기존에 등록해 둔 일정 알림 스케줄을 기기 내부에서 유지·복구하기 위해 사용됩니다.

3. 개인정보의 제3자 제공 및 위탁

본 앱은 사용자의 데이터를 수집하지 않으므로, 어떠한 제3자에게도 개인정보를 제공하거나 외부 업체에 처리를 위탁하지 않습니다. 타사 광고 SDK나 불필요한 분석 트래커를 포함하지 않습니다.

4. 데이터의 파기 및 백업 권한

  • 모든 데이터는 사용자의 기기에만 존재하므로, 앱을 기기에서 삭제(삭제/초기화)하면 저장되어 있던 모든 데이터는 즉시 영구 파기됩니다.
  • 사용자는 앱 내 '보관·백업' 메뉴를 통해 본인의 데이터를 직접 JSON 파일 형태로 내보내거나 가져올 수 있는 완전한 통제권을 가집니다.

5. 아동의 개인정보 보호

본 앱은 만 13세 미만 아동의 개인정보를 수집하지 않으며, 전 연령이 안전하게 사용할 수 있는 오프라인 생산성 도구입니다.
